01 Overview

The leaderboard displays race results and championship standings using the results entered by the organisers. Championship positions are calculated from each driver's points, penalties and tie-break information recorded across the championship.

02 Race results

  • Race result files are imported from Assetto Corsa Competizione JSON results.
  • Race results are displayed in finishing-position order, from first place downwards.
  • Each result can display the driver's name, car, finishing position, points awarded and best lap time.
  • The points awarded to a driver depend on the points system selected for that race when results are uploaded.

Important: The race result points shown for a session are the points awarded for that race. Championship standings then combine results across the championship and subtract recorded penalty seconds.

03 Points systems

The result uploader supports the following points options. The organiser selects the applicable system when uploading a race.

IMSA Points System

Uses the leaderboard's configured IMSA-style points mapping, with higher points for higher finishing positions.

1st Position 350 points down to 1 point for 39th position; other positions receive no points under this mapping.

No Points

Every driver in the uploaded session is assigned zero race points. Recorded penalties can still affect a driver's net championship points.

Points-system note: The selected points system is applied during result import. If a race is uploaded using the wrong system, an organiser should correct the recorded results through the admin tools.

04 Penalties

Recorded penalty time is accumulated for each driver across the championship. The leaderboard deducts 1 championship point for every 1 second of penalty time.

Driver A700 race points − 5 penalty seconds695
Driver B680 race points − 0 penalty seconds680

In this example, Driver A remains ahead because 695 net points is higher than 680.

  • Penalty seconds are shown separately in the championship standings.
  • Penalty seconds reduce championship points; they are not added to the accumulated race-time total used as a tie-break.
  • Only penalties recorded against the imported result and saved in the leaderboard data can be included in the calculation.

05 Championship standings

Championship standings are calculated by combining a driver's recorded results across the selected championship. The leaderboard ranks drivers in this order:

  1. Highest net points: total race points minus accumulated penalty seconds.
  2. Most race wins: if net points are equal, the driver with more recorded first-place finishes ranks higher.
  3. Lowest accumulated race time: if points and wins are equal, the lower total of valid recorded race times ranks higher.

Example: A driver with 500 race points and 10 penalty seconds has 490 net points. A driver with 485 race points and no penalty time has 485 net points, so the first driver ranks higher unless the points total is subsequently changed.

06 Race timing

  • Best lap times are shown for individual race results when a valid lap time is available.
  • Championship total time is the sum of valid recorded race total times for that driver.
  • Missing, zero or invalid total-time values are not added to the accumulated time.
  • Where drivers are tied on net points and wins, a driver with a valid accumulated time is placed ahead of a driver with no valid accumulated time.
  • Penalty time is tracked separately and is not added to the race-time tie-break total.

07 Entry lists

A championship may be associated with an entry list. If one is assigned, the public championship standings are filtered to include drivers assigned to that entry list. If no entry list is assigned, this additional filter is not applied.

Drivers must be associated with the correct driver record and entry list for them to appear in a restricted championship standings view.

08 Result integrity

To reduce duplicate or invalid entries during JSON import, the result-processing logic applies these checks:

  • Duplicate player/driver IDs within an uploaded result are excluded after the first occurrence.
  • Entries with the ACC invalid-time sentinel value are excluded from the accepted results.
  • Entries whose recorded total time is less than 70% of the leading result's total time are excluded by the import filter.

These are automated import filters. If a legitimate driver is missing or a result looks incorrect, an organiser should review the source JSON and the saved session results.

09 Corrections & administration

  • Organisers can review and edit recorded finishing positions, points and penalty seconds through the admin tools.
  • Session metadata can also be edited, and an uploaded session can be deleted by an authorised organiser.
  • When uploading a session with a session identifier already present, the importer replaces the existing records for that session rather than keeping duplicate copies.
  • Championship standings reflect the data currently saved in the leaderboard, so corrections to race results, points or penalties can change the standings.

For a suspected error, contact the championship organiser with the championship name, race round/session and driver name so the relevant result can be checked.
