1. Website & Branding Configuration

The Configuration tab governs the public appearance, branding titles, social media integration links, and administrative security parameters stored in the database.

Header & Branding

  • Page Title:
    Sets browser tab title (e.g. Your Racing Team | Leaderboard).
  • Community Name & Subtitle, Slogan:
    Community identification for textual header.
  • Logo Image & URL:
    Choose to display the default logo.png or a custom image url ie imgbb.
  • Theme Accent Color:
    Custom colour selector for theme accents.
  • Show Calendars:
    Show Calendar section on home page.
  • Time Zone Display:
    Time Zone to Display on race calendars

Socials & Admin Key

  • Social Links:
    Discord, YouTube, Instagram, Twitch. (Leave blank to hide icon).
  • ACCR Hotlap Sync:
    Toggle accr sync hotlap leaderboard integration.
  • Admin Password:
    Update Supabase user authentication password securely.
Pro-Tip: Always hit "Save Configuration" at the bottom of the section after changing theme colors or credentials.

2. League Management

Leagues represent top-level racing organizations or broad umbrella categories (e.g. "Your Racing Team Pro League", "GT3 Sprint League").

Core Actions & Workflows

Create League

Type the league name and click Create League. This becomes available in championship selection.

Edit Name

Click Edit to pop up the modification box. Renaming cascades across all linked components.

Delete League

Warning: Deleting cascades and removes all sub-championships, calendars, and uploaded results!

3. Championship Management

Championships are sub-tier series bound to a Parent League and a specific Season number (e.g. Community GT3 Cup - Season 2).

Core Actions & Workflows

Create Championship

Select Parent League & Type the championship name. Enter season number & optional options & click Create Championship.

Edit Championship

Rename & set if the championship is complete & if calendar is displayed on home page. Server name and join password options & entrylist also available.

Delete Championship

Warning: Deleting a championship removes all race results, calendars & corresponding drivers!

Entry-List Binding: You can optionally bind a predefined driver entry list to a championship. When race JSON files are parsed, drivers are filtered or categorized accordingly.
Season Complete Status: Toggle the seasonComplete checkbox when a season concludes to lock standings or flag completed series on public views.
Hide Calendar & Schedule: Enable the checkbox to hide the championship calendar and schedule.

4. Season Schedule Management

Set up your race calendar in advance. Scheduled races inform community drivers of track selection, date/time, practice/qualifying durations, and pit requirements.

Schedule Configuration Parameters

Track Selection: Choose from built-in ACC track keys (Monza, Spa, Nordschleife 24h, COTA, Kyalami, etc.).

Auto Round Numbers: Auto-calculates the next round number based on existing database entries.

Session Times: Set minutes for Practice, Qualifying, and Main Race.

Pit Rule Badges: Mandate Pitstops, Refuel requirements, or Tyre changes.

5. Upload Race Results (JSON Parser)

The core engine of the system automatically decodes ACC server result files (.json) exported directly from ACC dedicated servers.

1

Select Championship & Points System

Choose destination series and select either IMSA Points (350 for P1 down to P39) or No Points.

2

Select Result File (.json)

Click Browse File and choose the JSON output. The app parses UTF-16LE text and extracts leaderboard lines, best lap timing, split times, wet/dry flags, and post-race penalties automatically.

3

Driver Auto-Sync

Every participating driver is queried by Steam ID (playerId). Missing drivers are automatically created in the master driver list!

6. Race & Session Management (Post-Race Editor)

In case of stewards' decisions, time penalties, or manual points adjustments, the Race Management section provides granular position and penalty editing.

Cascade Dropdown Selector: Select League → Select Championship → Select Race Session.

Driver Results Table Editor

Adjust position values, manually assign extra points, or add seconds to Penalty Time. Click Save on the driver line to apply live adjustments.

Delete Entire Session

Removes all lap logs, positions, and points associated with the session JSON file from the database.

7. Driver & Entry-List Management

Organize your driver pool, inspect Steam IDs, and group drivers into custom Entry Lists (Pro Cup, AM Cup, Silver Class).

Entry Lists

Create custom driver pools (e.g. GT3 Pro Grid). Entry lists can be assigned during JSON upload or linked directly to championships.

Interactive Driver Table

Features real-time search filtering, Steam ID lookup, paginated grid controls, and live checkbox toggles for entry list assignments that auto-save instantly.

Troubleshooting & Frequently Asked Questions

JSON upload fails or yields "Invalid Structure"

Ensure the file is exported from an ACC dedicated server or ACC single-player event. Non-session result files or corrupted UTF-16 text files will trigger format exceptions.

Car model numbers display as numbers instead of names

The dashboard automatically decodes ACC car model IDs (e.g., ID 32 = Ferrari 296 GT3, ID 30 = BMW M4 GT3). If a brand new ACC DLC car model is released, it will fallback to displaying the numeric code until updated.

Auth session expired / Login overlay

If the admin token expires or Supabase connection drops, click Logout in the top right to return to the authentication overlay and re-enter credentials.
